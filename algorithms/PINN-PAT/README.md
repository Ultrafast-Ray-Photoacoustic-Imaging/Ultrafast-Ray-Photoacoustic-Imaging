#### A project of algorithm innovation: 
## Photoacoustic tomography reconstruction based on Physics Informed Neural Network  

**menu:**

`models`: Codes for network architecture and components.

`train`: Codes for network training and recording.

`run`: Executable python files for PAT reconstruction and forward simulation.

`phantom`: Phantom data.

`Sensor`: Sensor signal simulation via k-Wave.

`time_reversal`: Time reversal reconstruction images.

`ckpt`: Network state dicts after optimization.

`demo`: Visualization of optimized models.
